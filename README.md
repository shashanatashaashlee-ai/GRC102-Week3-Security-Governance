# GRC102 Week 3 – Security Governance

## Roles, Responsibilities and Accountability in Security Governance

### TechGlobal Governance Transformation Simulation

---

## Project Overview

This repository contains the work completed for the GRC102 Week 3 Practical Laboratory on Information Security Governance.

The practical uses the TechGlobal governance transformation scenario, in which the organisation is working to strengthen security governance, clarify accountability, improve decision-making and establish appropriate escalation and oversight mechanisms.

The work was developed from the perspective of a Lead Security Governance Consultant responsible for redesigning the organisation's security governance model.

---

## Key Areas Covered

This practical laboratory addresses:

- Security governance weaknesses and gap assessment
- Stakeholder identification and governance responsibilities
- Security governance organisational structure
- Roles, responsibilities and decision authority
- Governance committees and working groups
- Terms of Reference
- Governance decision-making and reporting
- RACI and accountability
- Cyber-risk escalation
- Segregation of duties
- Decision recording and assurance
- Board and executive cyber-risk oversight

## Scenario

**Organisation:** TechGlobal  
**Employees:** Approximately 2,500  
**Geographical Coverage:** Five global offices  
**Role:** Lead Security Governance Consultant  
**Module:** GRC102 – Information Security Governance  
**Practical:** Week 3 – Roles, Responsibilities and Accountability in Security Governance

## Objective

The objective of this practical laboratory is to design a scalable security governance model that establishes clear accountability, appropriate decision rights, cross-functional oversight, effective escalation and appropriate separation of duties.
